Stroke Risk Prediction System

Machine Learning-Based Health Risk Analysis

📌 Project Overview

This project predicts the likelihood of stroke in patients using machine learning techniques. It analyzes medical attributes such as age, glucose level, BMI, and lifestyle factors to provide early risk detection and support healthcare decisions.

🛠️ Technologies Used

  • Python
  • Machine Learning (Scikit-learn)
  • Pandas & NumPy
  • Data Visualization

⚙️ Features

  • Stroke risk prediction using ML models
  • Data preprocessing and feature engineering
  • Accuracy evaluation of models
  • User input-based prediction

📊 Model Details

The system uses classification algorithms such as Logistic Regression, Decision Tree, or Random Forest to predict stroke probability based on patient data.
